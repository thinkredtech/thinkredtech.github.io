# ThinkRED Website Design System

This document outlines the design system for the ThinkRED Technologies website, based on the company's [Brand Guidelines](/docs/brand-guidelines).

## Typography

### Fonts

- **Primary Display Font:** Comfortaa
- **Primary Text Font:** Montserrat

### Font Sizes and Styles

- **Display 1:** 80px/88px, Letter spacing: -2px, Comfortaa Medium 500
- **Display 2:** 48px/56px, Letter spacing: -1px, Comfortaa Medium 500
- **Heading 1:** 32px/40px, Letter spacing: -0.5px, Montserrat Medium 500 / Regular 400
- **Heading 2:** 24px/32px, Letter spacing: -0.25px, Montserrat Medium 500 / Regular 400
- **Heading 3:** 18px/26px, Letter spacing: -0.25px, Montserrat Medium 500 / Regular 400
- **Body 1:** 16px/24px, Letter spacing: 0, Montserrat Medium 500 / Regular 400 / Semibold 600
- **Body 2:** 14px/20px, Letter spacing: 0, Montserrat Medium 500
- **CTA Medium:** 14px, Letter spacing: 1.5px, Montserrat Semibold 600
- **CTA Small:** 12px, Letter spacing: 1px, Montserrat Semibold 600
- **Label 1:** 14px, Letter spacing: 1px, Montserrat Semibold 600
- **Label 2:** 12px, Letter spacing: 1px, Montserrat Semibold 600
- **Small Label:** 10px/14px, Letter spacing: 0.25px, Montserrat Semibold 600
- **Caption:** 12px/16px, Letter spacing: 0.25px, Montserrat Semibold 600 / Medium 500
- **Breadcrumb:** 10px/14px, Letter spacing: 0.25px, Montserrat Medium 500

## Color Palette

### Brand Colors

- **Primary Red:** #E4093E
- **Blue Accent:** #518CEA
- **Purple Accent:** #AE6CFC
- **Dark Gray:** #2A2A2A

### Typography Colors

- **Primary Text:** #2A2A2A
- **Secondary Text:** #7A7A7A
- **Tertiary Text:** #AAAAAA

### Background Colors

- **Main Background:** #FEFEFE
- **Flavoured Background:** #FEFEF6

## Spacing System
Based on 8px grid for consistent spacing:

- **Tiny:** 4px (0.25rem)
- **Very Small:** 8px (0.5rem)
- **Small:** 12px (0.75rem)
- **Regular:** 16px (1rem)
- **Medium:** 24px (1.5rem)
- **Big:** 32px (2rem)
- **Very Big:** 40px (2.5rem)
- **Very Very Big:** 48px (3rem)
- **Huge:** 56px (3.5rem)
- **Giant:** 64px (4rem)

## Shadows

- **Regular:** 0.8px 8px / 16% opacity
- **Small:** 0.4px 8px / 16% opacity
- **Subtle:** 0.4px 8px / 8% opacity
- **Subtle 2:** 0.4px 8px / 8% opacity

## Border Radius

- **Default:** 8px
- **Big Elements:** 16px

## Component Styles

### Buttons

- **Primary Button:** Background #E4093E, Text white, Padding 12px 24px, Border radius 8px
- **Secondary Button:** Border 2px #E4093E, Text #E4093E, Padding 12px 24px, Border radius 8px
- **Tertiary Button:** Text #E4093E, Padding 12px 24px, No border

### Cards

- Background white
- Border radius 8px
- Shadow Regular
- Padding 24px

### Forms

- Input fields with 8px border radius
- 2px border on focus with #518CEA color
- Labels using Label 1 style
- Error states with #E4093E color

### Navigation

- Sticky header with logo and main navigation
- Mobile hamburger menu with smooth transitions
- Active state with #E4093E underline or highlight

## Responsive Breakpoints

- **Mobile:** 0-767px
- **Tablet:** 768px-1023px
- **Desktop:** 1024px-1439px
- **Large Desktop:** 1440px+

## Animation Guidelines

- Smooth transitions (0.3s ease)
- Subtle hover effects
- Scroll-triggered animations for content sections
- 3D avatar assistant with interactive animations

## Image Treatment

- High-quality imagery
- Consistent aspect ratios
- Subtle rounded corners (8px)
- Optional subtle overlay gradient for text legibility

## Accessibility Considerations

- Minimum contrast ratio of 4.5:1 for text
- Focus states clearly visible
- Interactive elements with appropriate hover/active states
- Alternative text for all images
