# About Us Page Mockup Description

## Hero Section

- **Background:** Subtle gradient background in light color (#FEFEF6)
- **Headline:** "Our Journey" in Display 2 font (Comfortaa)
- **Subheadline:** Brief introduction to ThinkRED's story and mission
- **Visual Element:** Timeline indicator suggesting scrolling for story
- **Animation:** Subtle fade-in animation as page loads

## Timeline Section

- **Layout:** Vertical timeline with alternating left/right content blocks
- **Visual Style:** Connected nodes with ThinkRED red (#E4093E) line
- **Content Blocks:** Each milestone with year/title, description, and optional image
- **Milestones:**
  - Community roots (Mozilla/Fedora)
  - Red Hat experience
  - Upwork projects
  - ThinkRED founding
  - Current achievements
- **Animation:** Timeline elements animate in sequence as user scrolls

## Leadership Insights Section

- **Background:** White with subtle pattern
- **Title:** "Leadership Vision" in Heading 1
- **Layout:** Cards or profiles for leadership team
- **Content:** Brief quotes or insights about company philosophy
- **Animation:** Cards fade in and slightly rise as user scrolls to them

## Company Philosophy Section

- **Background:** Slightly darker background for contrast
- **Title:** "Our Philosophy" in Heading 1
- **Layout:** Three-column layout with key principles
- **Content:** Core values and approach to technology and client relationships
- **Visual Elements:** Icons representing each principle
- **Animation:** Icons have subtle hover animations

## Engineering Focus Section

- **Layout:** Split screen with text on left, visual representation on right
- **Title:** "Engineering Excellence" in Heading 1
- **Content:** Description of ThinkRED's engineering-focused approach
- **Visual:** Abstract illustration showing engineering concept
- **Animation:** Elements animate as user scrolls

## Call-to-Action Section

- **Background:** Primary red gradient (#E4093E)
- **Text:** "Join us in simplifying technology" in white, Display 2 font
- **Buttons:** "Talk to Us" and "Explore Services" in contrasting styles
- **Animation:** Background subtle wave animation

## Footer

- **Design:** Based on minimalist.in structure as requested
- **Sections:**
  - Logo and brief company description
  - Quick links to main pages
  - Services links
  - Contact information (<hello@thinkred.tech>)
  - Social media and GitHub links
  - Copyright and legal links
- **Style:** Clean, minimal with proper spacing and subtle separators

## Interactive Elements

- **3D Avatar Assistant:** Positioned in bottom right, reacts to scroll position and user interactions
- **Scroll Indicators:** Subtle arrows or dots indicating more content below
- **Hover Effects:** All buttons and clickable elements have smooth hover transitions
- **Scroll Animations:** Content elements animate in as they enter viewport

## Responsive Behavior

- **Mobile:** Single column layout, timeline adjusted for vertical flow
- **Tablet:** Two column layout where appropriate, adjusted spacing
- **Desktop:** Full layout with multiple columns and side-by-side content
- **Large Desktop:** Same as desktop with slightly increased maximum width and font sizes

## Accessibility Features

- High contrast between text and backgrounds
- Proper heading hierarchy
- Focus states for keyboard navigation
- Alternative text for all images and icons
