# Portfolio / Case Studies Page Mockup Description

## Hero Section
- **Background:** Subtle gradient background in light color (#FEFEF6)
- **Headline:** "Our Work" in Display 2 font (Comfortaa)
- **Subheadline:** Brief introduction to ThinkRED's portfolio and project approach
- **Visual Element:** Abstract grid or pattern suggesting project showcase
- **Animation:** Subtle fade-in and slide-up animation as page loads

## Filter Navigation
- **Background:** White with subtle shadow
- **Layout:** Horizontal filter bar with technology categories
- **Filter Categories:**
  - All Projects
  - Astro
  - React
  - Node.js
  - Spring Boot
  - Kubernetes
  - Firebase
- **Style:** Pills or tabs with active state in primary red (#E4093E)
- **Animation:** Smooth transition when switching filters
- **Responsive:** Horizontal scrolling on mobile, full width on desktop

## Project Grid
- **Layout:** Masonry or card grid with 3 columns on desktop, 2 on tablet, 1 on mobile
- **Cards:** Each project with:
  - Featured image
  - Project title
  - Client name (including ZeoMed Services as a placeholder)
  - Brief description
  - Technologies used (shown as tags)
- **Animation:** Cards fade in and slightly rise as user scrolls to them
- **Interaction:** Hover effect with slight scale and shadow increase
- **Filtering:** Smooth animation when filtering by technology

## Featured Project Section
- **Background:** Slightly darker background for contrast
- **Title:** "Featured Project" in Heading 1
- **Layout:** Full-width showcase with large image and detailed information
- **Content:** Comprehensive case study of a standout project
- **Details:** Challenge, solution, technologies, and outcomes
- **Visual:** Multiple screenshots or interactive preview
- **Animation:** Elements animate in sequence as user scrolls

## Project Detail Modal
- **Trigger:** Opens when a project card is clicked
- **Layout:** Full-screen modal with:
  - Image gallery/slider
  - Project title and client
  - Detailed description
  - Challenge and solution
  - Technologies used (with icons)
  - Results and metrics
  - Related projects
- **Navigation:** Previous/next project buttons
- **Animation:** Smooth open/close transitions

## Technology Showcase Section
- **Background:** White with subtle pattern
- **Title:** "Technologies We Excel In" in Heading 1
- **Layout:** Icon grid of technologies with hover information
- **Categories:** Frontend, Backend, DevOps, etc.
- **Animation:** Icons have subtle hover animations
- **Interaction:** Click to filter projects by that technology

## Client Testimonials
- **Background:** Light background (#FEFEF6)
- **Title:** "Client Feedback" in Heading 1
- **Layout:** Testimonial carousel or cards
- **Content:** Client quotes with name, position, and company
- **Visual:** Client logos or photos
- **Animation:** Smooth carousel transition or card reveal

## Call-to-Action Section
- **Background:** Primary red gradient (#E4093E)
- **Text:** "Ready to build something amazing together?" in white, Display 2 font
- **Buttons:** "Talk to Us" and "Explore Services" in contrasting styles
- **Animation:** Background subtle wave animation

## Footer
- **Design:** Based on minimalist.in structure as requested
- **Sections:**
  - Logo and brief company description
  - Quick links to main pages
  - Services links
  - Contact information (hello@thinkred.tech)
  - Social media and GitHub links
  - Copyright and legal links
- **Style:** Clean, minimal with proper spacing and subtle separators

## Interactive Elements
- **3D Avatar Assistant:** Positioned in bottom right, reacts to scroll position and user interactions
- **Scroll Indicators:** Subtle arrows or dots indicating more content below
- **Hover Effects:** All buttons and clickable elements have smooth hover transitions
- **Scroll Animations:** Content elements animate in as they enter viewport
- **Filter Interactions:** Smooth transitions when filtering projects

## Responsive Behavior
- **Mobile:** Single column project grid, horizontal scrolling filters
- **Tablet:** Two column project grid, adjusted spacing
- **Desktop:** Three column project grid with side-by-side content
- **Large Desktop:** Same as desktop with slightly increased maximum width and font sizes

## Accessibility Features
- High contrast between text and backgrounds
- Proper heading hierarchy
- Focus states for keyboard navigation
- Alternative text for all images and icons
- Keyboard-accessible filtering and modal navigation
