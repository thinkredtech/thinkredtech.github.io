# Landing Page Mockup Description

## Hero Section

- **Background:** Subtle gradient background in light color (#FEFEF6)
- **Headline:** "Simplify Technology & Experience" in Display 1 font (Comfortaa)
- **Subheadline:** Brief description of ThinkRED as an engineering-focused technology company
- **CTA Button:** "Talk to Us" in primary red (#E4093E)
- **Visual Element:** 3D vector avatar action figurine that reacts to scroll/hover
- **Animation:** Subtle parallax effect as user scrolls

## Services Overview Section

- **Layout:** Grid-based card layout with 3 columns on desktop, stacking on mobile
- **Cards:** Each service category with icon, title, and brief description
- **Categories:**
  - Web & Mobile Application Development
  - Product & Platform Engineering
  - DevOps & Infrastructure Automation
  - Technology Consultation
  - Design & Branding
  - Data & AI Services
- **Animation:** Cards fade in and slightly rise as user scrolls to them
- **CTA:** "Explore Our Services" button leading to services page

## Technology Stack Section

- **Background:** Slightly darker background for contrast
- **Title:** "Our Technology Stack" in Heading 1
- **Layout:** Horizontal scrolling carousel on mobile, grid on desktop
- **Content:** Icons/logos of technologies mentioned (Node.js, React, Vue, TailwindCSS, Spring Boot, etc.)
- **Animation:** Subtle floating animation for icons

## Vision for IDP Section

- **Layout:** Split screen with text on left, visual representation on right
- **Title:** "Internal Developer Platforms" in Heading 1
- **Content:** Brief explanation of ThinkRED's vision for IDP and infrastructure automation
- **Visual:** Abstract illustration or diagram showing IDP concept
- **Animation:** Elements animate in sequence as user scrolls

## Client Testimonials/Case Studies Preview

- **Background:** White with subtle pattern
- **Title:** "Success Stories" in Heading 1
- **Layout:** Testimonial cards with client logo, quote, and name/position
- **Placeholder:** ZeoMed Services highlighted as a client
- **Animation:** Cards slide in from sides as user scrolls

## Call-to-Action Section

- **Background:** Primary red gradient (#E4093E)
- **Text:** "Ready to simplify your technology experience?" in white, Display 2 font
- **Buttons:** "Talk to Us" and "Explore Services" in contrasting styles
- **Animation:** Background subtle wave animation

## Footer

- **Design:** Based on minimalist.in structure as requested
- **Sections:**
  - Logo and brief company description
  - Quick links to main pages
  - Services links
  - Contact information (<hello@thinkred.tech>)
  - Social media and GitHub links
  - Copyright and legal links
- **Style:** Clean, minimal with proper spacing and subtle separators

## Interactive Elements

- **3D Avatar Assistant:** Positioned in bottom right, reacts to scroll position and user interactions
- **Scroll Indicators:** Subtle arrows or dots indicating more content below
- **Hover Effects:** All buttons and clickable elements have smooth hover transitions
- **Scroll Animations:** Content elements animate in as they enter viewport

## Responsive Behavior

- **Mobile:** Single column layout, optimized spacing, hamburger menu
- **Tablet:** Two column layout where appropriate, adjusted spacing
- **Desktop:** Full layout with multiple columns and side-by-side content
- **Large Desktop:** Same as desktop with slightly increased maximum width and font sizes

## Accessibility Features

- High contrast between text and backgrounds
- Proper heading hierarchy
- Focus states for keyboard navigation
- Alternative text for all images and icons
