# Contact Page Mockup Description

## Hero Section

- **Background:** Subtle gradient background in light color (#FEFEF6)
- **Headline:** "Talk to Us" in Display 2 font (Comfortaa)
- **Subheadline:** Brief invitation to connect with ThinkRED for projects or inquiries
- **Visual Element:** Abstract communication or connection illustration
- **Animation:** Subtle fade-in and slide-up animation as page loads

## Contact Form Section

- **Background:** White with subtle shadow
- **Title:** "Get in Touch" in Heading 1
- **Layout:** Two-column layout with form on left, contact info on right (stacks on mobile)
- **Form Fields:**
  - Name (required)
  - Email (required)
  - Company/Organization
  - Phone Number
  - Project Type (dropdown)
  - Requirements (textarea)
  - Budget Range (optional)
  - Timeline (optional)
  - How did you hear about us? (dropdown)
  - File Upload (for project briefs/documents)
- **Submit Button:** "Send Message" in primary red (#E4093E)
- **Form Validation:** Real-time validation with helpful error messages
- **Success State:** Animated confirmation message after submission
- **Animation:** Form fields animate subtly on focus

## Contact Information Section

- **Layout:** Clean layout with icon + text for each contact method
- **Content:**
  - Email: <hello@thinkred.tech> (with clickable mailto link)
  - Location: Company address or general location
  - Social Media: Links to profiles with icons
  - GitHub: Link to company GitHub
- **Visual:** Decorative elements that match brand style
- **Animation:** Icons have subtle hover animations

## Schedule Discovery Call Section

- **Background:** Light background with subtle pattern
- **Title:** "Schedule a Discovery Call" in Heading 2
- **Content:** Brief description of the discovery call process
- **CTA Button:** "Schedule Now" linking to calendar booking
- **Visual:** Calendar or meeting illustration
- **Animation:** Elements animate as user scrolls

## Request Quote Section

- **Background:** Slightly darker background for contrast
- **Title:** "Request a Quote" in Heading 2
- **Content:** Brief explanation of the quote process
- **CTA Button:** "Request Quote" linking to relevant form section
- **Visual:** Quote or document illustration
- **Animation:** Elements animate as user scrolls

## FAQ Section

- **Background:** White with subtle pattern
- **Title:** "Frequently Asked Questions" in Heading 1
- **Layout:** Accordion-style expandable questions
- **Content:** Common questions about working with ThinkRED
- **Animation:** Smooth expand/collapse animations
- **Interaction:** Questions expand on click/tap

## Call-to-Action Section

- **Background:** Primary red gradient (#E4093E)
- **Text:** "Ready to transform your digital experience?" in white, Display 2 font
- **Buttons:** "Talk to Us Now" and "Explore Services" in contrasting styles
- **Animation:** Background subtle wave animation

## Footer

- **Design:** Based on minimalist.in structure as requested
- **Sections:**
  - Logo and brief company description
  - Quick links to main pages
  - Services links
  - Contact information (<hello@thinkred.tech>)
  - Social media and GitHub links
  - Copyright and legal links
- **Style:** Clean, minimal with proper spacing and subtle separators

## Interactive Elements

- **3D Avatar Assistant:** Positioned in bottom right, reacts to scroll position and user interactions
- **Form Interactions:** Smooth focus states and validation feedback
- **Hover Effects:** All buttons and clickable elements have smooth hover transitions
- **Scroll Animations:** Content elements animate in as they enter viewport

## Responsive Behavior

- **Mobile:** Single column layout, stacked sections, optimized form for touch input
- **Tablet:** Two column layout where appropriate, adjusted spacing
- **Desktop:** Full layout with multiple columns and side-by-side content
- **Large Desktop:** Same as desktop with slightly increased maximum width and font sizes

## Accessibility Features

- High contrast between text and backgrounds
- Proper heading hierarchy
- Focus states for keyboard navigation
- Alternative text for all images and icons
- ARIA labels for form fields
- Keyboard-accessible form and interactive elements
