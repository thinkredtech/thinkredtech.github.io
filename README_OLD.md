## 🚀 **Quick Start for Developers**

Get the ThinkRED Technologies website running locally in **3 simple steps**:

### **Step 1: Clone & Install**

```bash
# Clone the legendary repository
git clone https://github.com/thinkredtech/thinkredtech.github.io.git
cd thinkredtech.github.io

# Install dependencies with our magic script
npm install
```

### **Step 2: Setup Environment**

```bash
# Initialize your environment (creates .env file)
./scripts/env-manager.sh init

# Edit your environment variables
nano .env  # or use your favorite editor
```

### **Step 3: Launch & Conquer**

```bash
# Start the development server
npm run dev

# 🎉 Visit http://localhost:5173 to see the ThinkRED Technologies website!
```

> **🎯 Pro Tip**: Need more detailed setup instructions? Check out our [Setup Guide](docs/SETUP.md) for step-by-step instructions for all skill levels!
