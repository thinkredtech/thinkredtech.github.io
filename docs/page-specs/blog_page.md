# Blog / Insights Page Mockup Description

## Hero Section
- **Background:** Subtle gradient background in light color (#FEFEF6)
- **Headline:** "Insights & Articles" in Display 2 font (Comfortaa)
- **Subheadline:** Brief introduction to ThinkRED's thought leadership and engineering insights
- **Visual Element:** Abstract knowledge or technology illustration
- **Animation:** Subtle fade-in and slide-up animation as page loads

## Featured Article Section
- **Background:** White with subtle shadow
- **Layout:** Large featured article card with image, title, excerpt, and metadata
- **Content:** Latest or most important article highlighted
- **Visual:** Large featured image with overlay for text legibility
- **CTA:** "Read Article" button in primary red (#E4093E)
- **Animation:** Subtle hover effect with shadow increase

## Article Grid
- **Layout:** Card-based grid with 3 columns on desktop, 2 on tablet, 1 on mobile
- **Cards:** Each article with:
  - Featured image
  - Category tag
  - Article title
  - Publication date
  - Author
  - Brief excerpt
  - "Read More" link
- **Animation:** Cards fade in and slightly rise as user scrolls to them
- **Interaction:** Hover effect with slight scale and shadow increase

## Category Filter
- **Background:** Light background with subtle pattern
- **Layout:** Horizontal filter bar with article categories
- **Categories:** Technology, Engineering, Design, DevOps, AI, Industry Insights, etc.
- **Style:** Pills or tabs with active state in primary red (#E4093E)
- **Animation:** Smooth transition when switching categories
- **Responsive:** Horizontal scrolling on mobile, full width on desktop

## Search Section
- **Layout:** Full-width search bar with icon
- **Functionality:** Real-time search suggestions as user types
- **Animation:** Smooth expansion on focus
- **Results:** Instant filtering of articles based on search term

## Newsletter Subscription
- **Background:** Light background (#FEFEF6) with subtle pattern
- **Title:** "Stay Updated" in Heading 2
- **Content:** Brief description of newsletter benefits
- **Form:** Email input field and "Subscribe" button
- **Visual:** Newsletter or notification illustration
- **Animation:** Form fields animate subtly on focus

## Popular Tags Cloud
- **Background:** White with subtle shadow
- **Title:** "Popular Topics" in Heading 2
- **Layout:** Tag cloud with varying sizes based on popularity
- **Interaction:** Tags are clickable to filter articles
- **Animation:** Subtle hover effect on tags

## Call-to-Action Section
- **Background:** Primary red gradient (#E4093E)
- **Text:** "Have a technology challenge?" in white, Display 2 font
- **Buttons:** "Talk to Us" and "Explore Services" in contrasting styles
- **Animation:** Background subtle wave animation

## Footer
- **Design:** Based on minimalist.in structure as requested
- **Sections:**
  - Logo and brief company description
  - Quick links to main pages
  - Services links
  - Contact information (hello@thinkred.tech)
  - Social media and GitHub links
  - Copyright and legal links
- **Style:** Clean, minimal with proper spacing and subtle separators

## Article Page Template
- **Hero:** Large featured image with title overlay
- **Content:** Well-formatted article with proper typography hierarchy
- **Author Section:** Author image, name, title, and brief bio
- **Related Articles:** Grid of related content at bottom
- **Share Buttons:** Social media sharing options
- **Comments:** Optional commenting system

## Interactive Elements
- **3D Avatar Assistant:** Positioned in bottom right, reacts to scroll position and user interactions
- **Scroll Indicators:** Subtle arrows or dots indicating more content below
- **Hover Effects:** All buttons and clickable elements have smooth hover transitions
- **Scroll Animations:** Content elements animate in as they enter viewport
- **Filter Interactions:** Smooth transitions when filtering articles

## Responsive Behavior
- **Mobile:** Single column article grid, horizontal scrolling filters
- **Tablet:** Two column article grid, adjusted spacing
- **Desktop:** Three column article grid with side-by-side content
- **Large Desktop:** Same as desktop with slightly increased maximum width and font sizes

## Accessibility Features
- High contrast between text and backgrounds
- Proper heading hierarchy
- Focus states for keyboard navigation
- Alternative text for all images and icons
- Keyboard-accessible filtering and navigation
