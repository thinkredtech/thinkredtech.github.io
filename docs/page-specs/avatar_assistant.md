# 3D Avatar Assistant Mockup Description

## Design Concept

- **Character Style:** 3D vector action figurine based on ThinkRED branding
- **Color Scheme:** Primary red (#E4093E) with accent colors from brand palette
- **Personality:** Professional yet friendly, embodying ThinkRED's "Simplify Technology & Experience" mission
- **Size:** Compact but visible, positioned in bottom right corner of the screen

## Visual Elements

- **Base Design:** Humanoid figure with slightly stylized proportions
- **Branding Elements:** Incorporates ThinkRED logo elements or colors
- **Facial Features:** Simple, expressive face with minimal details
- **Outfit:** Tech-inspired clothing with ThinkRED branding elements
- **Accessories:** Optional tech gadgets or tools that relate to services offered

## Animation States

- **Idle State:** Subtle breathing animation and occasional glances at user
- **Greeting:** Waves and smiles when page first loads
- **Scroll Reaction:** Changes pose or expression based on scroll position
- **Hover Interaction:** Reacts when user hovers over it
- **Click Interaction:** Offers help or suggestions when clicked
- **CTA Highlight:** Points to important call-to-action elements on page

## Interactive Behaviors

- **Page Context Awareness:** Displays different poses/expressions based on current page
- **Scroll Progress:** Animations triggered at specific scroll points
- **User Interaction:** Responds to mouse movements and clicks
- **Help Mode:** Expands to offer navigation assistance when activated
- **Minimized State:** Can be collapsed to a smaller icon if user prefers

## Technical Implementation

- **3D Technology:** WebGL-based implementation using Three.js
- **Performance:** Optimized for low resource usage across devices
- **Fallback:** Simplified 2D version for devices with limited capabilities
- **Loading:** Progressive loading to ensure fast initial page load

## Responsive Behavior

- **Desktop:** Full-sized avatar with complete animation set
- **Tablet:** Slightly reduced size with maintained functionality
- **Mobile:** Minimized version that expands only when activated
- **Position Adjustment:** Repositions appropriately based on screen size

## Accessibility Considerations

- **Alternative Navigation:** All functionality accessible without avatar interaction
- **Reduced Motion:** Option to minimize animations for users with motion sensitivity
- **Screen Reader Support:** Proper ARIA labels for all interactive elements
- **Keyboard Navigation:** Full functionality available through keyboard controls

## Integration with Site Elements

- **Service Highlights:** Points to or demonstrates services as user scrolls
- **Form Assistance:** Offers guidance when user interacts with contact forms
- **Navigation Help:** Suggests relevant pages based on current content
- **CTA Enhancement:** Draws attention to primary call-to-action buttons
